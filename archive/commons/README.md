# Archive: Crap Map (Commons washroom compass)

Our first idea: a compass pointing to the nearest washroom **inside** University Commons.
We pivoted to Campus Compass because GPS doesn't work indoors and the building's steel
bends the compass. These pages are kept for the demo story; they still run.

- `washrooms.js` — washroom coordinates inside Commons
- `testlocation.html` — GPS test page
- `guide-test.html`, `demo.html`, `field-test.html` — early compass/arrow test pages
